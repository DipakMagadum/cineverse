# 🎬 CINEVERSE

CINEVERSE is a full-stack movie website built using the MERN stack.  
I created this project to improve my frontend and backend development skills while building something that looks modern and works like a real-world movie platform.

The application allows users to browse movies, search content, create accounts, manage watchlists, and access admin features.

---

## Features

- User Login & Registration
- Browse Movies
- Search Functionality
- Watchlist Feature
- Admin Panel
- Responsive UI
- Protected Routes
- Fast frontend with Vite

---

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router DOM
- Vite

### Backend
- Node.js
- Express.js
- MongoDB

## Getting Started

### Install Frontend

```bash
cd client
npm install
npm run dev
```

### Install Backend

```bash
cd server
npm install
node server.js
```
